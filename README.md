# 🃏 Memory Card Game

A classic **Memory Matching Card Game** built with HTML, CSS, and JavaScript.

## Features
- 8 pairs of cards (16 total)
- Flip animation
- Match detection
- Move counter
- Restart button
- Win message

## How to Run
Open `index.html` in your browser.

## Tech Stack
- HTML5
- CSS3 (Transitions, Flexbox/Grid)
- Vanilla JavaScript
